# Prime Minds Nexus Website

This version includes:
- Responsive public website
- Official supplied Prime Minds Nexus logo
- About, programs, resources, events, leadership and contact sections
- Membership interest form
- Client-side confirmation/storage for testing

## Important before public launch
The membership form currently stores test submissions in the visitor's browser using localStorage. It is NOT a central membership database.

To make it production-ready, connect the form to one of:
1. Google Forms / Google Sheets
2. Supabase or Firebase
3. A secure custom backend

Also replace placeholder contact details and event information and add the official WhatsApp Community link.

## Open locally
Open `index.html` in a browser.
